# TorqVault

A cinematic automotive database website concept built for GitHub Pages.

## Features
- Responsive luxury automotive design
- Search cars by model, brand, year, or engine
- Brand filters
- Car detail modal
- Save favorites with localStorage
- Compare up to 3 cars
- Mobile navigation
- No build step and no backend required

## Deploy to GitHub Pages
1. Create a new GitHub repository.
2. Upload the contents of this folder to the repository root.
3. Go to **Settings → Pages**.
4. Choose **Deploy from a branch**.
5. Select your main branch and `/ (root)`.
6. Save. GitHub will publish `index.html`.

The included vehicle artwork is original vector artwork made for this demo. Vehicle specifications are sample/reference data and should be verified before using the site as a factual database.
